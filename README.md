# BTC Market Analyzer

A Python-based tool for analyzing historical Bitcoin prices and exploring cryptocurrency market trends.

## Features

* Historical Bitcoin price analysis
* Price change calculations
* Market volatility analysis
* Price trend visualization

## Technologies

* Python
* Data analysis
* Financial market analytics

## Getting Started

The repository contains the Python source code and a requirements.txt file listing the project’s dependencies.

To install the dependencies:

pip install -r requirements.txt

## Project Purpose

This project explores how Python can be used to analyze cryptocurrency market data and visualize price movements.
